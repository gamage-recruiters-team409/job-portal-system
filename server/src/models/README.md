# Shared Model Ownership

Only the approved primary owner may create or make major structural changes to each model.

| Model or domain | Primary owner |
|---|---|
| User and Authentication | Bimsara |
| JobSeekerProfile | Hiba |
| Company | Injas |
| Job | Disura |
| Application | Madushika |
| SavedJob | Madushika |
| Notification | Danaja |
| Category | Sahan |
| Skill | Sahan |
| Report | Anuruddhika |
| SupportMessage, only if approved | Anuruddhika |

A required change to another owner's model must be discussed with the owner, approved by the Team Lead, explained in the pull request and documented for affected modules.

# Project Documentation

Store approved project documentation, technical decisions, API contracts and integration references in this directory.

- `architecture/` — architecture and structure decisions
- `api/` — endpoint contracts and integration references
- `database/` — model ownership and database decisions
- `ownership/` — module, API, model and layout ownership
- `setup/` — local development and onboarding instructions

Do not add confidential company documents, credentials, real personal data, private Postman environments or production information.

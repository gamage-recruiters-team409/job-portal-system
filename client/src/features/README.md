# Frontend Feature Ownership

Each developer should place module-specific frontend code inside the approved feature directory.

| Feature directory | Primary member | Main responsibility |
|---|---|---|
| `authentication/` | Bimsara | Registration, login, verification and access control UI |
| `public-jobs/` | Bimsara | Home, public navigation, job discovery and job details |
| `job-seeker-profile/` | Hiba | Job seeker dashboard, profile and CV management |
| `applications/` | Madushika | Apply flow, history, details and timeline |
| `saved-jobs/` | Madushika | Save, remove and view saved jobs |
| `employer-profile/` | Injas | Employer dashboard and company profile |
| `job-management/` | Disura | Employer job creation, editing and management |
| `applicant-management/` | Kalana | Applicant lists, details and status actions |
| `admin/` | Sahan | Admin management, moderation, categories and skills |
| `notifications/` | Danaja | Notification centre, dropdown and statistics cards |
| `reported-jobs/job-seeker/` | Anuruddhika | Job seeker report form and submission flow |
| `reported-jobs/admin/` | Sahan | Admin report review and moderation screens |
| `help-support/` | Anuruddhika | About, Contact, FAQ, Help and approved support form |

Do not move another member's work, create a duplicate feature folder or implement an unapproved module without coordination.

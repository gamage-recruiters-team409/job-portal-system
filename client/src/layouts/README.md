# Shared Layout Ownership

| Layout area | Primary owner | Usage |
|---|---|---|
| Standard non-admin top navigation | Kalana | Authenticated non-admin modules |
| Standard non-admin sidebar | Injas | Job Seeker and Employer dashboard areas |
| Shared public footer | Bimsara | Public and public job-discovery pages |
| Admin top navigation | Sahan | Admin area |
| Admin sidebar | Sahan | Admin area |

Other developers must reuse the approved shared components. Major layout changes require discussion with the owner, Team Lead approval and testing against affected modules.
